## Evidence rules
- **Merged:** GitHub records a merge, not a guarantee of correct deployment or passed tests.
- **Documented:** A repository specification, test script or procedure exists, not necessarily a completed test run.
- **Observed:** A specific finding was reported or independently inspected; retain dated supporting screenshots or logs.
- **Pending:** A test, approval or artifact still needs completion. Do not mark it passed without evidence.

Attach approved proposal, original planning timeline, meeting/interview records (if actually conducted), wireframes, verified schema export and ERD, test run logs, anonymized screenshots and acceptance sign-off separately. Never include real student personal information, passwords, tokens or database secrets in annexes.

This package does not change application code, database schema or deployment.
